# Разобрать Reel и проверить факты

Разбор доступного содержания ролика, проверка существенных тезисов по источникам и предложения экспериментов.

Авторский скилл `instagram-reel-local`, опубликованный bushkarev-max под лицензией MIT.

[Полный текст скилла](skills/instagram-reel-local/SKILL.md).

## Установка в Codex

1. Скачайте ZIP репозитория или клонируйте: `git clone https://github.com/bushkarev-max/instagram-reels-analysis.git`.
2. Прочитайте `skills/instagram-reel-local/SKILL.md`. Проверьте существующие установки с тем же именем, включая прежние каталоги скиллов; не перезаписывайте локальные правила автоматически.
3. Скопируйте целиком папку `skills/instagram-reel-local` в `.agents/skills/` своего проекта либо в `~/.agents/skills/` для всех проектов.
4. Начните новую сессию в нужном проекте и проверьте доступность скилла.

Каталоги и ручная установка описаны в [официальной документации OpenAI](https://developers.openai.com/api/reference/cli). Совместимость установщиков других ассистентов здесь не проверена.

## Пример

«Используй instagram-reel-local: проанализируй загруженное видео и проверь существенные утверждения».

Для видео нужны доступный файл/инструмент просмотра либо субтитры и кадры; для проверки фактов — поиск и доступ к источникам. При локальной обработке могут понадобиться отдельно установленные FFmpeg и распознавание речи. Скилл не устанавливает их, не запрашивает пароли/cookies и не выдаёт разбор подписи за просмотр видео.

## Проверки и ограничения

Это инструкции без встроенных программ, аккаунтов или платных API. Не устанавливаются автоматически ни программы, ни сам скилл.

Python 3, без внешних зависимостей:

```sh
python3 scripts/check_public.py
python3 -m unittest discover -s tests -v
```

Проверяются явный состав файлов, текстовый формат, символические ссылки, имена и описания скилла, типовые ключи/токены, email, локальные пути, IP-адреса и посторонние GitHub URL. Сканер не гарантирует обнаружение любой PII и не заменяет чтение каждого файла. Подробности — [SECURITY.md](SECURITY.md).

Проверки пакета и шесть тестов сканера пройдены локально. Проверки в GitHub Actions запускаются на push и pull request. Качество ответов модели на реальных заданиях этими проверками не подтверждается.
